# Word Puzzle Frontend

A word puzzle game built with React, TypeScript, and Vite. Features user authentication and an interactive keyboard interface.

## Tech Stack

- React 19
- TypeScript
- Vite (with Rolldown)
- CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Features

- Interactive word guessing game
- User authentication (login/register)
- On-screen keyboard
- Guess tracking and display
- Responsive design
